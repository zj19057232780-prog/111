## 1. 四种方案的区别

| 方案 | 暂定模型名 | 论文中心问题 | 主要贡献层级 | 当前适用判断 |
|---|---|---|---|---|
| 一：表征与元训练并重 | **SCG-MAML** | 如何同时组织时频尺度信息、上下文信息和任务在适配后的损失差异？ | 编码器＋任务重加权，两条方法主线 | **首选**；与当前实现和参考对话最连贯 |
| 二：特征编码主导 | **CCSK-MAML** | 选择不同空间范围的特征后，如何利用整幅时频图的上下文校准特征通道？ | 整合式编码设计为主，GGM-RW 为附加训练策略 | 若 GGM 增益尚不稳定，更适合收敛写作范围；编码器贡献本身仍需消融支撑 |
| 三：任务加权主导 | **PAG-MAML** | 为什么 query loss 相同的任务也可能需要不同的外循环权重？ | 适配后损失差信号及其权重变换为主，编码器为实现载体 | 研究问题较集中；需等权、query-loss、gap 的严格配对与跨主干验证 |
| 四：优化稳定性主导 | **ICG-MAML** | 如何在引入上下文调制与非均匀任务权重时控制训练扰动？ | 恒等初始化的上下文调制＋受约束任务加权 | **暂不优先**；现有代码能解释设计，尚不能证明稳定性优势 |

这里的排列是“当前适用程度”，不是原创性、期刊等级或预计录用概率排序。四种方案组织的是同一套现有方法；名称变化不构成算法变化。

## 2. 与现有代码一致的共同基础

| 对象 | 当前实际内容 | 论文中建议的表述 |
|---|---|---|
| 输入 | 单通道 64×64 STFT 图 | STFT time–frequency representation |
| LSK-lite | 32/64/96 三阶段；大核分解与空间选择门控 | 基于 LSK 的尺度选择特征提取；“尺度”指卷积空间范围，不直接等同于物理频率尺度 |
| 当前 GCNet | attention pooling 汇聚共享全局上下文，默认 channel_mul 融合；调制项以恒等映射为中心，带可学习残差尺度 | 基于 GC 的全局上下文通道校准 |
| GGM-RW | 源任务一阶 pilot 后计算 G_i=max(0,L_Qi−L_Si_post)，由同批任务的 gap 生成 detached 权重，再做正式二阶 MAML | 基于适配后经验损失差的外循环任务重加权 |
| PU | artificial9state 类别池内随机 5-way；当前默认 1-shot、每类 15-query；三个 N15 源工况→N09_M07_F10 | 同标签跨工况少样本诊断；不等同于未见故障类别识别 |
| CWRU | 10-way；当前默认 1-shot；C0/C1/C2→C3 | CWRU 内跨负载/转速工况验证 |
| 选模 | 目标域 validation 标签参与 checkpoint 选择 | 明示目标验证选模；不能写严格 target-unseen domain generalization |

PU 三个源工况为 N15_M01_F10、N15_M07_F04、N15_M07_F10；类别池为 K001、KA01、KA05、KA03、KA07、KA08、KI01、KI03、KI07。CWRU 工况为 C0_1797rpm、C1_1772rpm、C2_1750rpm→C3_1730rpm。

**网络前向路径**是 STFT→LSK-lite→GCNet→GAP→Linear。**GGM-RW 属于元训练流程**，根据 pilot 的损失生成权重，再加权正式二阶 MAML 的 query objective；绘图时应放在外循环分支，不能画成分类器之后的推理层。

参考对话中的 LGTF Encoder／LGG-MAML 可以作为历史候选保留，但建议采用“scale–context”作为新的论证用语。LSK 原设计已经选择大空间感受野，GC 原设计则利用对空间查询位置共享的全局上下文；把二者简单分成“LSK 只处理局部、GC 专门补全局”不够准确。[LSKNet 原文](https://openaccess.thecvf.com/content/ICCV2023/html/Li_Large_Selective_Kernel_Network_for_Remote_Sensing_Object_Detection_ICCV_2023_paper.html)、[GCNet 原文](https://arxiv.org/abs/1904.11492)。

## 3. 方案一：SCG-MAML——尺度、上下文与任务损失差联合组织

**核心论点**

面向跨工况少样本轴承诊断，在表征阶段通过尺度选择和全局上下文校准组织时频特征，在元训练阶段根据任务适配后的 support–query 损失差调整任务对外循环的贡献。

**命名层级**

- 模型：**SCG-MAML**，Scale–Context–Gap MAML。
- 编码器：**SC-TFE**，Scale–Context Time–Frequency Encoder，尺度—上下文时频编码器；对应 LSK-lite＋当前 GCNet。
- 元训练策略：**PAG-R**，Post-Adaptation Gap Reweighting，适配后损失差重加权；对应代码 GGM-RW。
- 编码器内部沿用“LSK-based scale selection”和“global context calibration（GCC）”说明来源，不把两个已有机制分别包装成从零提出的新算法。

**候选标题**

*Scale-Selective Context Encoding and Gap-Guided Meta-Learning for Cross-Condition Few-Shot Bearing Fault Diagnosis*

基于尺度选择上下文编码与损失差引导元学习的跨工况少样本轴承故障诊断。

**可用的贡献表述草稿**

1. 构建面向 STFT 输入的尺度—上下文时频编码器，将基于 LSK 的多范围特征选择与基于 GC 的全局上下文通道校准整合于少样本元学习框架。
2. 设计适配后损失差引导的任务重加权策略，在相同 pilot 适配参数下比较 support 与 query 损失，通过标准化、截断、均匀混合和权重上限生成外循环任务权重，并将其用于正式二阶 MAML。
3. 在 PU 与 CWRU 的明确跨工况协议下，分别考察编码设计和任务重加权的作用，并报告其计算代价与适用边界。此条是待完成的验证贡献，结果出来前不能改成“证明显著优越”。

**最值得借鉴的库内论文**

- **AMAML（Mu 2025）**：借鉴“问题缺口→模块→总算法→消融”的全文骨架；其 Table 5 用三个因素的八组合验证对应模块。这里借论证组织，不移植其自适应损失或 AMOS 机制。[论文](https://doi.org/10.1016/j.engappai.2024.109748)
- **Meta-ARSN（Zeng 2026）**：作为“特征网络＋任务加权”直接近邻，明确我们的差别在加权信号、权重控制和正式元梯度流程。它已经给出 query-loss 任务加权公式。[论文](https://doi.org/10.1109/ICSADL67539.2026.11451812)
- **Sun 2025 多通道融合改进 MAML**：借鉴表征与元训练两条问题线，以及注意力对照表的安排。[论文](https://doi.org/10.1109/ICMSP68723.2025.11407529)

**论文骨架**

引言：跨工况少样本问题→现有表征与等权外循环的局限假设→两条设计主线。方法：任务定义→SC-TFE→PAG-R→总算法。实验：跨工况主表→编码组件→加权信号→额外代价。讨论：两条主线何时有帮助、何时没有帮助。

**最小关键证据**

先做同协议 CNN4-MAML、LSK-MAML、LSK＋GC-MAML、LSK＋GC＋GGM-MAML 四组，再加一个在同一完整主干上的 query-loss 加权对照。若要声称 GC 与 GGM 存在协同，而非分别贡献，还要在 LSK 主干上补齐 GC（关/开）×GGM（关/开）四组合；仅顺序添加模块无法识别交互作用。

**选择理由**

两条主线与现有实现对应清楚，能兼顾算法部分与故障诊断实验；也最接近参考对话的原始思路。当前最需要解决的是 GGM 独立增益是否在配对协议中成立。

## 4. 方案二：CCSK-MAML——上下文校准的选择核表征

**核心论点**

将研究重点集中在“尺度选择后的特征如何被全局上下文校准”，以整合式时频编码器作为论文主体。GGM-RW 可作为附加训练策略报告。

**命名层级**

- 模型：**CCSK-MAML**，Context-Calibrated Selective-Kernel MAML。
- 编码器：**CCSK Encoder**，Context-Calibrated Selective-Kernel Encoder。
- GGM-RW 保留代码原名，作为附加训练策略；如果其增益不能复现，可从主贡献与题名中撤下。
- “Context-Calibrated”修饰提取后的特征，不表示 GC 动态修改了 LSK 的卷积核参数。

**候选标题**

*Context-Calibrated Selective-Kernel Representations for Cross-Condition Few-Shot Bearing Fault Diagnosis*

面向跨工况少样本轴承故障诊断的上下文校准选择核表征。

**可用的贡献表述草稿**

1. 构建上下文校准的选择核编码器，在 STFT 特征上先选择不同空间范围的响应，再利用共享全局上下文进行通道重标定。
2. 通过受控的编码组件比较，考察尺度选择、全局上下文融合和快速适配之间的关系，并分析不同工况下的收益与失效情形。此项属于待验证的机制分析贡献，不另算一个全新算法。
3. 将所构建编码器用于 PU 与 CWRU 跨工况少样本诊断，并把任务重加权作为独立附加因素评价。

**最值得借鉴的库内论文**

- **SMLDMN（Huang 2026）**：借鉴多尺度与注意力模块的动机展开、特征模块到元学习的衔接。它还使用无标签目标数据与伪标签，相关机制不能移入我们的协议描述。[论文](https://doi.org/10.1016/j.engappai.2026.113828)
- **Sun 2025**：借鉴不同注意力模块的对照安排；其 64×64 灰度输入不能未经核实就写成与本项目相同的 STFT。[论文](https://doi.org/10.1109/ICMSP68723.2025.11407529)
- **MFEML（Li 2025）**：借鉴特征模块如何连接解释性分析与不同输入条件的实验。[论文](https://doi.org/10.1016/j.ymssp.2025.112370)

**论文骨架**

引言主要展开跨工况下的特征选择问题；方法以编码器为最大篇幅，MAML 作任务适配基础，GGM 放在独立训练策略小节；结果先给编码效果，再给特征分析与附加策略结果。

**关键证据**

固定等权 MAML，比较固定多尺度与选择门控、无 GC 与 GC、标准 GC 融合与当前融合。参数量、训练预算和数据协议尽量匹配，并报告差异。可视化 LSK 空间门控及 GC 通道调制应配合性能消融；好看的热图不能独立证明识别机制。噪声条件未经验证时不使用“去噪编码器”名称。

**选择条件**

当编码器的配对收益成立，而 GGM 的额外收益仍不稳定时适用。代价是“已有 LSK＋GC 组合是否足够构成贡献”会成为更集中的审稿问题，需要说明整合设计与实验证据，而不能依靠改名解决。

## 5. 方案三：PAG-MAML——适配后损失差驱动的元任务重加权

**核心论点**

绝对 query loss 不能区分所有任务适配状态；在同一适配参数下同时观察 support 与 query 损失，研究其差值是否能提供有用的外循环权重信号。

**命名层级**

- 模型：**PAG-MAML**，Post-Adaptation-Gap-Guided MAML。
- 核心策略：**PAG-R**，与方案一中的 GGM-RW 别名一致。
- 编码器：SC-TFE，为具体实现主干；如果要主张策略具有主干适用性，必须补充其他编码器验证。

**候选标题**

*Post-Adaptation Loss-Gap Reweighting for Cross-Condition Few-Shot Bearing Fault Diagnosis*

面向跨工况少样本轴承故障诊断的适配后损失差重加权。

**最直观的动机例子**

两个任务的 query loss 都是 0.8，适配后的 support loss 分别是 0.2 和 0.7，则正 gap 分别为 0.6 和 0.1。仅看 query loss 的加权信号无法区分它们；当前 GGM 会相对提高第一个任务的贡献。这个例子只说明信号不同，不能推出第一个任务一定更值得学习或加权一定更优。

**可用的贡献表述草稿**

1. 以相同 pilot 适配参数下的 query–support 正损失差描述任务的经验适配差异，构建区别于绝对 query-loss 加权的外循环任务信号。
2. 将该信号映射为受约束的元批次权重，并通过 detached pilot 与正式二阶更新分离，使权重本身不引入额外的可微优化路径。信号与变换构成一项完整策略，不应拆成数项基础算法创新。
3. 在匹配的任务序列、评价 episode 和多个主干上，考察 gap 加权相对于等权与 query-loss 加权的收益、敏感性及计算开销。此条目前是证据计划。

**最值得借鉴的库内论文**

- **Meta-ARSN**：最直接的机制比较对象；式(16)–(18)已有 query-loss 任务权重及外循环目标，因此论文应问“为什么使用适配后损失差”，不能把“首次给任务不同权重”作为创新。[论文](https://doi.org/10.1109/ICSADL67539.2026.11451812)
- **TUBR-ML（Wang 2025）**：借鉴任务差异问题→形式化设计→算法→机制验证的论证；它改任务初始化/内循环与先验正则，我们改外循环权重。[论文](https://doi.org/10.1016/j.engappai.2025.110200)
- **RT-ACM（Wang 2025）**：借鉴非均匀任务贡献的动机、消融及过程展示；它涉及目标相关性与课程，当前 GGM 不等同于这些机制。[论文](https://doi.org/10.1109/JSEN.2025.3567614)

**论文骨架**

引言先展示绝对 query loss 的信息局限→提出适配后差值假设。方法先定义信号，再写权重变换与总算法，编码器随后交代。结果先验证信号差异和同协议加权对照，再展示完整诊断结果与跨主干适用性。

**关键证据**

- 采用同一 pilot、任务序列和主干，仅将加权信号从 gap 换为 query loss，标准化、温度、均匀混合和 cap 等变换保持一致，以隔离“差值信号”的作用。
- 原文式 query-loss weighting 可另列近邻基线；若仅移植其加权公式，应标注“基于原文的加权对照”，不能称为完整复现 Meta-ARSN。
- 至少在 CNN4 和 LSK 系列两个主干上比较，避免只证明某个大模型与某组权重组合有效。
- 检查训练后期 gap 很小时，z-score 是否仍将微小差别放大为明显权重差异；记录 gap 量级、权重分布和控制参数敏感性。
- 若分析“gap 能预测后续泛化收益”，应使用独立保留的查询样本或后续评价任务，不能只在生成权重的同一批 query 上自证。
- 报告额外 pilot 带来的训练时间与显存开销；“没有新增可训练参数”不等于“没有计算代价”。

**选择条件**

只有在配对多 seed、跨工况以及至少两个主干的对照中得到有解释力的结果，才建议将此方案作为主叙事。当前历史结果尚不足以确定 GGM 的独立稳定收益。

## 6. 方案四：ICG-MAML——恒等初始化的上下文调制与损失差引导

**核心论点**

围绕引入上下文调制与非均匀任务权重后的训练行为展开，研究保守的特征调制初始化及任务贡献约束在二阶元学习中是否有实际价值。

**命名层级**

- 模型：**ICG-MAML**，Identity-Centered and Gap-Guided MAML。
- GC 子模块：**IC-GCC**，Identity-Centered Global Context Calibration。
- 元训练策略：PAG-R；均匀混合、warm-up 和权重上限是其控制部分，不单列若干算法创新。
- LSK-lite 保留为尺度选择主干。

**候选标题**

*Identity-Centered Context Modulation with Gap-Guided Meta-Learning for Few-Shot Bearing Fault Diagnosis*

基于恒等中心上下文调制与损失差引导元学习的少样本轴承故障诊断。

**代码能够支持的设计描述**

当前默认 channel_mul 路径可写为：

y = x + γ · x ⊙ [2σ(h(c)) − 1]，

其中 c 是 attention pooling 得到的全局上下文，h 为通道变换，γ 是可学习的残差尺度，初值为 10⁻⁴。当前末层卷积零初始化，使 h(c)=0，因此 GC 子模块在初始化时 y=x。这个等式仅描述该 GC 模块默认配置，不能扩展成整网恒等或整个训练期间 γ 始终很小。

**可用的贡献表述草稿**

1. 在基于 LSK 的编码器后引入以恒等映射为中心初始化的上下文通道调制，并明确其与二阶适配过程的连接方式。
2. 将该调制与损失差任务加权结合，考察特征变化与任务权重变化对元训练行为的影响。
3. 通过匹配的训练过程分析评价这些控制的作用。只有结果支持后，才可写“降低训练波动”或“提高稳定性”。

**文献借鉴与归属**

AMAML 可借鉴将元优化问题与过程证据相连的组织方式；TUBR-ML 可借鉴围绕任务优化问题展开形式化论证的方式。[AMAML](https://doi.org/10.1016/j.engappai.2024.109748)、[TUBR-ML](https://doi.org/10.1016/j.engappai.2025.110200)。GCNet 是全局上下文机制的原始来源，恒等/零初始化的思路亦不能据此宣称首次提出。[GCNet](https://arxiv.org/abs/1904.11492)

**关键证据**

比较标准 GC 与当前融合；再分别控制中心化调制、残差尺度初值，以及 GGM 的混合、warm-up、cap。记录梯度范数、异常损失尖峰、训练失败频率、跨 seed 波动、准确率与训练代价。比较时保持梯度裁剪、调度器、BN 处理等一致，避免把其他控制的效果归给所命名模块。

先核查 cap 实际触发频率；若主实验中从未触发，就不能用当前结果说明“cap 带来了改进”。任务权重上限约束的是标量 w_i，并不自动给元梯度范数或训练收敛提供保证。

**选择条件**

该方案需要最多额外过程证据，也最容易被追问其相对于已有残差尺度和初始化设计的独立贡献。当前适合保留为讨论/消融方向，暂不作为首选标题与主创新。

## 7. 统一的实验与表述边界

1. **配对比较优先。** 固定数据划分、预处理、训练任务序列、评价 episode、适配步数、checkpoint 选择规则和预算；多 seed 结果报告配对差值及离散程度。大量测试 episode 不能替代独立训练 seed。
2. **实验设置按数据集明确。** PU 当前为人工 9 状态池中的 5-way；CWRU 当前为 10-way。扩展 PU 留一工况轮换或 shot 时，属于后续实验，不应写成已经完成。评价协议沿用目标验证选模时须披露。
3. **创新归属分清。** LSK、GC、MAML、残差尺度等均有既有来源；可主张经过验证的组合设计与具体 GGM 策略，不把改名或迁移领域本身当作充分原创性依据。
4. **gap 的解释收紧。** G_i 是有限样本 episode 中的经验损失差；它不是已校准可靠性、域距离、无偏泛化误差，也不保证 gap 大的任务更有价值。当前较大正 gap 被上调权重，不能写反。
5. **不要混同课程。** 从均匀权重逐步增加自适应权重的 warm-up 不自动构成 easy-to-hard 课程；本实现不按目标任务相关性挑选任务。
6. **不要混同去噪或物理建模。** 当前 LSK/GC 不包含显式阈值去噪、物理频率对齐或转速不变性约束。空间选择门控也不是归一化的两分支概率。
7. **命名是候选。** 四个模型缩写做过初步公开短语检索，未发现明确同名机器学习模型；检索不能保证名称唯一，更不构成算法原创性判定。正文采用前仍需统一题名、图注、公式和代码映射。

**贡献一：构建尺度—上下文时频编码器 SC-TFE。** 针对跨工况少样本轴承诊断中时频特征的多尺度表达与全局上下文建模需求，构建尺度—上下文时频编码器 SC-TFE。该编码器将选择性大核特征提取与轻量全局上下文校准相结合，通过多范围特征选择和上下文引导的通道重标定，形成面向少样本任务适配的时频表征。

### 9.3 方法章节与证据的分工

建议 Method 按以下顺序组织：

1. Task formulation：跨工况任务、S/Q 与目标验证数据访问边界。
2. SC-TFE：尺度选择、上下文校准及结构公式。
3. PAG-R：pilot gap 定义与权重变换公式。
4. Integration with second-order MAML：参数/计算图关系、状态控制、正式更新与总算法。

不另造 MCA Module。第四小节引用前两节已经定义的结构和权重公式，集中说明连接方式，避免把轻量化、初始化、detach 等再推导一次。网络图将 STFT→SC-TFE→GAP/分类头放在前向路径；pilot、权重生成、support 内循环和 outer update 在元训练区域标出。

支持第三条需要两类不同证据：

- **实现正确性证据**：参数副本隔离，pilot 前后指定 BN buffers 与 RNG 状态不受额外 pass 的持久改变，正式元梯度不经过权重分支。它们证明代码执行路径与描述一致。
- **方法价值证据**：在固定数据、任务序列、梯度裁剪与选模规则的条件下，比较合理的初始化/残差尺度设置及 pilot 方案，报告准确率、训练时间、峰值显存和过程波动。它们才用于判断集成选择是否值得保留。

BN/RNG 控制缺失的对照首先是正确性诊断，不应人为制造有状态污染的弱基线来宣称算法优越。若声称 GC 与 PAG-R 存在协同作用，需另外补齐固定 LSK 主干上的 GC×PAG-R 四组合；顺序添加模块不足以识别交互。
