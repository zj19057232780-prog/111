## 更适合接入当前PyTorch项目的公共实现

- [EasyFSL](https://github.com/sicara/easy-few-shot-learning)同时提供ProtoNet、MatchingNet、RelationNet。属于第三方库，不是三个模型各自原作者代码。已核对README方法目录，并打开matching_networks.py及relation_networks.py页面。可以统一接入数据接口，仍需核对与原论文的损失、关系头、上下文嵌入等差异。
- [learn2learn](https://github.com/learnables/learn2learn)提供PyTorch元学习工具，可供MAML实现参考；保留二阶更新设置，不将一阶近似冒称完全相同的MAML实验。

上述经典实现主要面向Omniglot/MiniImageNet等图像任务，不是已验证可直接运行的PU/CWRU轴承项目。接入需对齐灰度STFT输入、类别采样、support/query、工况划分及评价方式。本轮没有克隆仓库、安装依赖或进行运行验证。
