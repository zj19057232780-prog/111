# ResNet18-FT与TL-WDCNN配置使用说明

> 2026-09-10更新：按用户要求，当前PU/CWRU默认已改为普通`resnet18`，源域从零监督训练、目标直接预测，无支持集微调。详见《普通ResNet18配置使用说明.md》。下文resnet18_ft仅为保留的历史可选接口，TL-WDCNN流程不变。

## 切换与运行

PU修改`IFMAML-master/config_pu.py`的PU_CONFIG，CWRU修改`IFMAML-master/config_cwru.py`的CWRU_CONFIG：

```python
'method': 'resnet18_ft',  # 或 'tl_wdcnn'
'run_mode': 'train_test',
```

在IFMAML-master目录、ifmaml2环境运行：

```powershell
python maml_train_pic.py   # PU
python run_cwru_maml.py    # CWRU
```

`train`仅训练，`test`加载本方法best权重测试，`train_test`训练后测试。显式`--train`/`--test`优先；新模型需先训练。此次保留用户原来的method选择，不自动启动正式实验。

| 模型 | 配置值 | 输入与实现 |
|---|---|---|
| ResNet18-FT | resnet18_ft | 当前单通道STFT图；标准[2,2,2,2]残差块布局；不下载或使用ImageNet预训练权重 |
| TL-WDCNN | tl_wdcnn | 原始一维振动窗口；首层宽卷积kernel=64、stride=16，五个卷积块，100维全连接特征；使用自适应池化兼容PU/CWRU窗口长度 |

两者均为项目内实现。TL-WDCNN的自适应池化是针对当前输入长度的改编，论文应说明，不能称为原作者代码的逐行复现。模型自动关闭原项目增强模块与GGM-RW。

## 训练与测试协议

1. 在所有配置的源域类别上普通监督预训练，Adam优化交叉熵；源域分类头覆盖完整源类别池。
2. 每个验证/测试episode复制源域模型与BN状态，重新初始化N-way分类头，仅使用该episode的support标签微调；采用新的SGD优化器。
3. 使用query评估，query标签不参与微调。每个episode结束后丢弃适配模型，参数、优化器和BN状态不传到下一任务。
4. 使用固定验证任务与固定局部分类头初始化选择best，最终测试读取该权重。

这两种方法不做元训练。`n_way`、`k_shot`、`q_query`及源/目标工况仍由原配置控制。预训练曲线的train accuracy是源域完整类别监督分类准确率，valid accuracy是目标验证集N-way微调准确率，两者分类范围不同。

默认`ft_bn_mode='batch'`：support/query各自使用批量统计，与当前批量query评测约定一致。`frozen`使用源域BN运行统计。`ft_scope='head'`仅冻结编码器参数；若也要冻结其BN统计，应同时设`ft_bn_mode='frozen'`。正式比较应统一说明BN协议，不能将batch结果描述为单张独立推断。

## 专用参数

| 参数 | 默认值 | 含义 |
|---|---:|---|
| ft_pretrain_epochs | 100 | 源域监督预训练轮数 |
| ft_pretrain_batch_size | 64 | 预训练批大小 |
| ft_pretrain_lr | 0.001 | Adam学习率，当前不使用学习率调度 |
| ft_weight_decay | 0.0001 | 预训练权重衰减 |
| ft_pretrain_max_batches | 0 | 每轮批数上限，0为全量；正数仅用于限量调试 |
| ft_validation_episodes | 16 | 每轮固定验证任务数；正式实验可增加 |
| ft_validation_seed | 2026 | 固定验证采样与局部头初始化种子 |
| ft_patience | 0 | 按验证准确率早停，0关闭 |
| ft_steps | 10 | 每个目标任务support微调步数 |
| ft_lr | 0.01 | support微调SGD学习率 |
| ft_scope | all | all微调全网络，head仅分类头参数 |
| ft_bn_mode | batch | batch批量统计；frozen源域运行统计 |

这两种方法使用上述ft参数，不使用MAML的epochs、inner_lr、outer_lr、adaptation_steps或test_inner_steps控制训练/微调。`--quick`仅进行1轮、至多2个预训练批次和2个验证任务，用于检查链路。正式运行关闭QUICK_TEST/--quick，并令ft_pretrain_max_batches=0。

自动权重名包含算法、任务及ft配置哈希；改变ft配置通常会改变权重路径。测试时保持训练配置，或显式指定正确的`--model_path`。best旁保存展开配置及源域类别信息。

## TL-WDCNN的数据对齐

首次使用时只读加载本地MAT，按原预处理的顺序、随机种子、窗口位置重放采样，并逐窗口重新生成STFT，与已有PNG做精确核对；不覆盖PNG。之后在内存中复用一维数据。每个一维窗口独立标准化，源域/验证/测试的类别、窗口对应和划分沿用现有图片数据。

需要保留原始MAT与当前配置匹配的PNG。若改变预处理参数或原数据后PNG未同步，程序会明确报错，避免静默使用不同样本。首次核对耗时高于直接加载图片属于正常现象。
