# 非元学习经典对比模型建议

参考已核对的Zotero原文，建议补充以下候选，而非仅为增加数量全部加入主表。

| 模型/方案 | 库内使用先例 | 当前项目建议 |
|---|---|---|
| CNN4 + Fine-tuning（CNN4-FT） | TUBR-ML原文对比CNN + fine-tune，EZDSRWQ4第4.4节 | 优先。普通监督学习源域预训练，每个目标episode恢复预训练权重，仅用support微调后评估query；无跨适配过程的元梯度。CNN4是本项目具体骨干选择，不宣称与原文CNN完全相同 |
| WDCNN / TL-WDCNN | RSNLRN，Gao 2025，5KVJW2E6第IV节 | 轴承领域传统深度基线；少样本目标适应用预训练+微调版本并明确标注。原方法用一维原始振动，保留原始时间段与标签对应，不把二维STFT卷积冒称原版WDCNN |
| ResNet-18 / ResNet18-FT | Meta-ARSN，5UIFPAHY第VI节对比ResNet-18 | 检验普通较深网络。FT为本项目拟采用的适应协议，不宣称该文也采用同样FT。STFT单通道输入，主实验不额外引入ImageNet预训练数据 |
| Deep CORAL（DCORAL） | AMAML，PASMYJ36第4.5节和用户Table7 | 二阶特征统计对齐的域适应。需要明确额外无标签目标训练池，独立报告数据访问预算 |
| DANN | AMAML同节；MCA-DAML也列DANN | 对抗域适应。与DCORAL组成两种域对齐路线，同样需要额外无标签目标训练池 |

参考来源：
- TUBR-ML：https://doi.org/10.1016/j.engappai.2025.110200
- RSNLRN：https://doi.org/10.1109/JSEN.2025.3547258
- Meta-ARSN：https://doi.org/10.1109/ICSADL67539.2026.11451812
- AMAML：https://doi.org/10.1016/j.engappai.2024.109748
- WDCNN原始论文：https://doi.org/10.3390/s17020425
- DANN原始论文：https://www.jmlr.org/papers/v17/15-239.html
- Deep CORAL原始论文：https://arxiv.org/abs/1607.01719
- 普通预训练/微调少样本基线参考：https://arxiv.org/abs/1904.04232

建议先加入CNN4-FT；若希望保留STFT输入并增加深网络对照，再加ResNet18-FT。若强调故障诊断领域经典性，则优先TL-WDCNN，需新增原始信号输入适配。DCORAL/DANN仅在确定目标无标签池及划分后进入域适应扩展实验；不静默使用最终query做对齐，不随意将原方法改成元学习。若只使用当前support做对齐，应明确标为少样本改编版本，并评估1-shot下协方差估计是否有效。

同一episode内所有方案使用相同way、shot、query，微调方法每个episode重置模型与优化器状态，禁止沿测试任务累计学习。预训练使用全源域语义标签；目标episode随机抽类时，输出头需按局部类别正确重建或映射，不能直接将源域全类别预测与局部0..N-1标签比较。调参使用validation，query标签仅作评价。

本文仅为候选补充，不替换已接入的四个元学习模型，不修改代码或运行实验。全为元学习并非原则错误，但增加预训练+微调对照能直接检验元训练本身的价值。经典CNN4-MAML与普通CNN4-FT不能混称CNN。
