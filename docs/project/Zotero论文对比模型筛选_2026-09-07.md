## 2. 逐项适用性与原文定位

### Meta-ARSN

- **用途：**近期方法近邻。注意力残差特征＋任务加权＋MAML，与SCG-MAML整体结构最接近；适合检验完整方法相对于近邻方案的效果。
- **复现边界：**原文采用预训练＋FOMAML，权重依赖query loss；完整复现需补齐预训练及协议细节。仅移植query-loss权重时应标作机制对照，不称完整Meta-ARSN。
- **证据：**[Zotero 5UIFPAHY](zotero://select/library/items/5UIFPAHY)；PDF p.5 §VI-B；pp.6–7结果与Meta-ResNet对照。

### LA-PID＋MAML

- **用途：**近期元优化对照。通过分层PID改变任务内适配，是与PAG-R外循环重加权不同的优化路径，可检验优化改进的替代方案。
- **复现边界：**库内原文实验为通用图像分类、跨域和回归，没有PU/CWRU轴承验证；迁移到本项目需实现原更新规则，不直接引用原准确率。
- **证据：**[Zotero W8D4AWC4](zotero://select/library/items/W8D4AWC4)；PDF pp.10–12 Tables I–III；pp.12–15跨域及过程分析。

### AMAML

- **用途：**特征与元训练联合改进对照。注意力编码、自适应损失和元优化组成完整方案，适合与SC-TFE＋PAG-R的联合设计比较。
- **复现边界：**保留原AFEN/ALC/AMOS的必要机制；按本项目重新构造任务。不能只复现其编码器就标为完整AMAML。原文ProtoNet引用具体改进工作，复现经典ProtoNet另引原始论文。
- **证据：**[Zotero PASMYJ36](zotero://select/library/items/PASMYJ36)；PDF pp.14–16 §4.5、Fig.17/19、Tables 8–9；p.10 Table 5组件。

### TUBR-ML

- **用途：**任务自适应与正则化对照。同属少样本跨域故障诊断，通过任务初始化、适配和正则控制任务差异，是PAG-R的重要替代路线。
- **复现边界：**原文包含CWRU 10-way 1/5-shot，与CWRU主协议贴近；仍须统一工况组合与数据划分。其原方法不是简单outer-loss weighting。
- **证据：**[Zotero EZDSRWQ4](zotero://select/library/items/EZDSRWQ4)；PDF pp.9–11 §4.4、Table 11、Fig.10。

### MFEML

- **用途：**元特征增强对照。提供近期的特征增强元学习方法，可检验SC-TFE相对于另一类特征设计的作用；原文含CWRU及跨试验台实验。
- **复现边界：**包含自适应平方化输入与特征增强；不能未经说明统一改成STFT后仍称原版。保留原输入处理时使用相同原始信号段与数据划分。
- **证据：**[Zotero Q7HZR3FV](zotero://select/library/items/Q7HZR3FV)；PDF pp.14–15 Tables 4–5、§4.3.2；pp.7–13实验协议。

### RSNLRN

- **用途：**近期度量型元学习对照。同时涉及PU/CWRU，PU具有三源一目标工况组织；与MAML类对比形成不同学习范式的覆盖。
- **复现边界：**原输入为CWT，PU主要3-way，当前项目为STFT及9类池随机5-way；需要重新运行本项目协议，保留关系度量和原输入机制。
- **证据：**[Zotero 5KVJW2E6](zotero://select/library/items/5KVJW2E6)；PDF p.7 §IV对比方法；pp.8–10及pp.13–14实验表。

### 多通道融合改进MAML（原文未给统一模型缩写）

- **用途：**结构与训练策略近邻。CWRU十状态、64×64单通道图像和MAML，与当前输入形态和任务设置接近。
- **复现边界：**原文未明确采用STFT；其多通道指网络特征分支，并非必然需要多传感器。全模型对比与注意力替换实验分开列。
- **证据：**[Zotero VTSUPL2U](zotero://select/library/items/VTSUPL2U)；PDF p.4 Table 5；p.5 Table 6、§IV-C。

### BIML

- **用途：**脉冲网络元学习对照。提供不同于常规CNN元学习的近期轴承诊断方法，可拓宽比较的模型类型。
- **复现边界：**原实验为双转子与传统轴承自建试验台；需要SNN及其STBP/STDP学习机制，迁移成本预计较高。不是直接改CNN主干即可复现。
- **证据：**[Zotero 9ZFLFEZG](zotero://select/library/items/9ZFLFEZG)；PDF p.1正式卷期；pp.5–7实验数据与比较方法。

### Task-Supervised ANIL

- **用途：**特征复用与快速适配对照。可检验完整MAML内循环相对于主要适配分类头的方案是否值得，也覆盖任务自适应损失路线。
- **复现边界：**保留原头部内循环与任务监督机制；不能为了统一而强制它全模型适配。原文称five但实际列出七个方法，此处按列出的名称记录。
- **证据：**[Zotero 9KCA2TSQ](zotero://select/library/items/9KCA2TSQ)；PDF p.1正式卷期；p.6 §IV-B、pp.7–9结果。

### ETML；TML为其非集成版本

- **用途：**Transformer表征对照。直接检验选择性大核＋上下文校准相对于Transformer元学习的表征方案；原文含CWRU实验。
- **复现边界：**ETML包含多个模型加权投票，需计入整套集成的参数、训练及推理开销；单模型比较应使用并标注TML。
- **证据：**[Zotero A954VIIQ](zotero://select/library/items/A954VIIQ)；PDF pp.7–9方法/数据；p.14 §4.1.4、Table 5。

## 3. 建议主对比表的组合

建议先形成以下8个外部对照，另加SCG-MAML，共9行：

| 类别 | 建议模型 | 要回答的问题 |
|---|---|---|
| 基础优化型元学习 | MAML | 相对标准任务适配是否有收益？ |
| 基础度量型元学习 | ProtoNet | 相对无需目标任务梯度适配的原型分类是否有收益？ |
| 近期联合改进 | AMAML | 相对已有特征、损失和优化联合设计是否有收益？ |
| 近期任务优化 | TUBR-ML | 相对任务自适应与正则化是否有收益？ |
| 近期特征增强 | MFEML | 相对另一种元特征设计是否有收益？ |
| 近期度量型方法 | RSNLRN | 相对轴承跨工况关系网络是否有收益？ |
| 特征复用与适配 | Task-Supervised ANIL | 完整模型适配与主要适配分类头的取舍是什么？ |
| 2026整体近邻 | Meta-ARSN | 相对已有注意力残差网络＋任务加权是否有收益？ |

其中Meta-ARSN的正式预训练、权重与任务协议细节仍需核实后实现；若无法忠实复现，不能用随意补出的版本填表。可以先完成其余7个对照，将LA-PID作为研究侧重点允许时的2026进阶候选。ETML/TML、Sun改进MAML与BIML为扩充候选，不要求全部同时加入。

经典基线虽较早仍有明确作用：AMAML、Sun、Meta-ARSN和Task-Supervised ANIL均保留MAML和/或ProtoNet；MFEML同时比较MAML、TML、ETML。文献依据表明“经典锚点＋近期方法”的组合可用，但最终取舍仍是针对本项目的建议。MAML、ProtoNet、RelationNet等若在论文中使用，应引用各自原始方法，而不是只引用采用它们的近期轴承论文。

若希望扩大基础算法覆盖，可补充RelationNet、FOMAML或MAML++。库内经典轴承实现可参考Li 2021的[STFT-MAML/MLFD](https://doi.org/10.1016/j.neucom.2021.01.099)、Zhang 2021的[轴承MAML](https://doi.org/10.1109/TIA.2021.3091958)，跨工况组织可参考[Chen 2023](https://doi.org/10.1109/TII.2022.3165027)。这些经典项不是2025/2026新提出的模型。

## 5. 两类比较必须分清

**完整模型对比：**固定原始信号段、划分、source/target、way/shot/query、目标数据访问权限、选模规则及评价episode；保留各方法必要的预处理、主干和适配机制，并报告参数量与计算代价。不强制所有方法变成同一STFT编码器或二阶MAML，否则会破坏ETML、MFEML、ANIL等方法的定义。

**本方法的机制对照：**在相同SC-TFE、pilot和正式更新流程下比较等权、query-loss信号和PAGR信号，尽量只替换待检验因素；另做编码器消融。它们用于证明PAGR/SC-TFE的作用，不能冒充外部文献的完整模型。原文式query-loss weighting与保持同一权重变换只更换信号的对照应分别标注。

多seed采用匹配的数据划分和评价任务；在任务采样本身就是方法的核心时（如ATML/课程），不能强行固定成相同采样顺序，应固定候选任务池与预算并披露策略差异。只报告重新运行本项目协议得到的结果，不拼接不同论文的准确率。

本次交付是选型与原文证据，不代表已审计所有官方代码、复现完整性或算子兼容性。证据扫描见 literature_review_20260907/baseline_evidence_scan.json，最终候选见 baseline_selected_models.json。期刊日期补核来源包括[MFEML出版社页](https://www.sciencedirect.com/science/article/pii/S0888327025000718)，其正式时间为2025年3月；BIML的PDF卷期为2025年8月、Task-Supervised ANIL为2024年7月。
