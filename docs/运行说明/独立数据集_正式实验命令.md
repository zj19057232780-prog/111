# 独立数据集正式实验命令

2026-10-19：CWRU、PU 独立跨工况；跨数据集实验停用。华中科技大学 HUST 已由独立入口 run_hust_huazhong.py 接入；run_experiment.py 不接受 --dataset hust。三库逐模型的单任务/单seed及多任务/多seed命令见[三数据集命令清单](三数据集_单模型实验命令清单.md)。

在 IFMAML-master 目录运行，使用已安装 CUDA PyTorch 的 Python。AutoDL 保持 IFMAML-master 与 comparison_models 平级。

## 每条为一个模型、一个 seed、该库全部四个目标工况

```bash
python -u run_experiment.py --dataset cwru --tasks all --method scg_maml --input stft --shots 1 --seed 3 --action train-test --device cuda
python -u run_experiment.py --dataset pu --tasks all --method scg_maml --input stft --shots 1 --seed 3 --action train-test --device cuda
python -u run_experiment.py --dataset cwru --tasks all --method maml --input nostft --shots 5 --seed 24 --action train-test --device cuda
python -u run_experiment.py --dataset pu --tasks all --method mfeml --input stft --shots 5 --seed 38 --action train-test --device cuda
```

`--method` 可换为 protonet、matchingnet、relationnet、maml、amaml、tubr_ml、mfeml、scg_maml；tl_wdcnn 为补充。常规主表为 1/5-shot，3-shot 可选；seed 为3、24、38，可用 `--seeds 3 24 38` 一次运行。默认500轮，对比方法 patience100；SCG-MAML及消融不早停。TL-WDCNN预训练上限100轮。

CWRU 任务为 C0–C3，PU 为 P1–P4。支持 `--tasks C0,C2` 或 `--tasks P1 P4`；每个任务为同库其余工况训练、指定工况验证/测试，不再使用跨库 T1–T8。

## 输入与数据路径

- 显式指定 `--input stft` 或 `--input nostft`；nostft 保持各模型原生长度/形状。SCG-MAML和A0–A3不支持nostft。
- PU STFT 默认 pu_data_processed；可用 `--data-root /实际图片目录`。PU nostft 默认 pu_data_mat，可用 --data-root 指定原始MAT目录。
- CWRU nostft 默认 CWRU，可用 --data-root 指定。CWRU STFT 默认从 CWRU 原始MAT生成独立的逐任务缓存，位置为输出根目录/_data；不覆盖原有缓存。
- CWRU STFT 可用 --raw-root 指定原始MAT目录，或 --data-map task_paths.json 指定已核查的各任务图片目录（JSON如 {"C0":"/data/C0","C1":"/data/C1"}）。已有缓存必须与工况及预处理匹配，不应把单任务图片当成全部任务。
- 新主线每类15 query；跨库的10 query不沿用。

## 消融、检查与补测

```bash
python -u run_experiment.py --dataset pu --tasks all --method a0 --input stft --shots 1 --seed 3 --action train-test --device cuda
python -u run_experiment.py --dataset cwru --tasks C0 --method maml --input nostft --shots 1 --seed 3 --action check --device cuda
python -u run_experiment.py --dataset pu --tasks P1 --method maml --input stft --shots 1 --seed 3 --action smoke --device cuda
python -u run_experiment.py --action test --checkpoint-dir /实际运行目录/seed3/P1 --device cuda
```

消融把 a0 换成 a1/a2/a3，分别对应 CNN4、LSK、LSK+GC、SCG+AGR。check 检查数据（CWRU STFT必要时生成缓存），smoke仅少量训练/测试，不可填论文。`--action train` 仅训练；test使用保存的配置与最佳验证权重，且校验源码/数据/权重。运行时请勿覆盖源码。

结果默认位于 IFMAML-master/experiment_results；--output-root 可改根目录。formal、_smoke、_checks分离，时间戳防止覆盖。每任务保存配置、签名、源码快照、权重、结果和预测；原生复现方法另保留自己的episode记录。每次批跑生成 runs.json 与 summary.json。完整三seed统计先在每个seed内平均工况，再跨seed计算样本标准差。

历史跨库结果仍在原结果目录，已停用；河内HUST材料在 archive/HUST_Hanoi_retired_20261019。旧快照内的HUST均指河内，不能作为华中实验来源。
