# 全状态池权重测试

脚本：项目根目录 `test_all_classes.py`。使用平时训练项目的 Python 环境，不需要重新进行元训练。

```powershell
python test_all_classes.py --weights-dir "你的权重文件夹" --device cuda
```

文件夹可以包含多模型、多任务、多seed子目录；也可以直接传一个权重文件。递归识别带 `resolved_config.json` 或同名 `.config.json` 的权重。AMAML、TUBR-ML、MFEML还需要同目录的 `method_config.json`。请保留原运行目录，不要只拷贝一个权重文件。实际数据仍从保存的配置路径读取；建议在训练机器和原环境运行。

先查看识别结果（不测试）：

```powershell
python test_all_classes.py --weights-dir "你的权重文件夹" --list-only
```

没有CUDA时用 `--device cpu`。不传任何参数时会提示输入文件夹路径。自定义测试量：

```powershell
python test_all_classes.py --weights-dir "你的权重文件夹" --episodes 100 --shots 1 --queries 15 --seed 24
```

## 分类与适配

- 使用当前配置/数据加载器的完整状态池，不强行更换分类预设。例如PU `artificial_9state` 用9类，而不是健康/内圈/外圈3类，也不是随机抽取的5类。
- 每个episode同时包含全部N类，每类取K个support及Q个query，二者无重复。默认K取原配置，Q=15，20个episode；`--queries 0`使用每类除support以外的全部测试样本（显存占用更大）。
- 固定5类的MAML/SCG-MAML/AMAML/TUBR-ML/MFEML分类头改成N类，重新初始化最后一层；其余权重严格加载。只用support适配，步数默认取保存的配置；`--steps`可显式覆盖。
- ProtoNet/MatchingNet/RelationNet沿用自己的全support分类接口；迁移学习沿用原有support微调方法。
- 每个episode恢复模型参数及BN缓冲，避免前一任务影响下一任务。保留各实现的query批统计行为，并非额外宣称严格非传导测试。
- 这是额外的全类别N-way实验，不能替代或直接与原5-way表格比较。扩展头后效果需要实际检验，不保证保留原5-way准确率。若状态池恰好等于原分类头输出数，则保留原头。
- 当前支持项目的PU、CWRU、华中HUST，经典few-shot/迁移基线、SCG-MAML及消融、AMAML/TUBR-ML/MFEML。不支持任意外部模型和监督ResNet18协议。

## 输出

默认保存到 `outputs/all_class_test_时间戳/`，每份权重独立目录，原权重/历史结果不覆盖。

| 文件 | 内容 |
|---|---|
| summary.csv | 所有权重的准确率、Macro-F1、Weighted-F1及成功/失败状态 |
| metrics.json / episode_metrics.json | 汇总及各episode指标，数值为百分数 |
| classification_report.json | 每类precision/recall/F1，数值为0–1 |
| confusion_matrix.png/.pdf | 全状态池混淆矩阵，蓝色、逐行百分比，汇总全部episode |
| confusion_counts.csv / confusion_percent.csv | 矩阵原始计数和百分比，带类别名称 |
| tsne_all_classes.png/.pdf | 第0个全类别任务适配后的query特征；每类不同颜色 |
| tsne_features.npz | 实际特征、真实标签、二维坐标及类别名称，可后续重画 |
| class_mapping.json | 图中编号与真实状态名称的对应关系 |
| predictions.csv / episodes.jsonl | 预测及support/query在各类测试数组内的索引 |
| resolved_config.json / data_signature.json | 本次配置和数据指纹 |
| job.json / evaluation_code_sha256.json | 本次参数及评测代码指纹 |
| test.log / error.txt | 测试日志；失败原因 |

t-SNE只用一个共同适配模型的特征，不拼接多个独立episode的坐标空间，也不挑选“最好看”的任务。默认15 query/类时，PU9类共有135个点。混淆矩阵汇总全部episode，两图覆盖相同状态池但统计样本数量不同。

若历史运行有数据签名和权重SHA256则核验；没有历史签名的旧权重会标记为未验证。脚本记录当前评测代码，不保证与历史源码完全相同。默认20个episode只提供快速额外评估；跨episode标准差不是跨训练seed标准差，不自动合并不同任务/seed作为论文均值。
