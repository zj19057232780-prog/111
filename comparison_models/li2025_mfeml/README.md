# Li 2025 MFEML独立对比模型

实现 **自适应方阵化＋CNN4＋SimAM/ECA元特征增强＋二阶MAML**。数据与任务复用项目PU/CWRU，模型和训练参数优先依论文。原文映射及未明确细节见 [notes.md](notes.md)；这是项目协议复现，不是原文数据集与结果表的完整重现。

## 输入接口

| 参数 | 输入流程 |
|---|---|
| `--input no_stft` / `--input nostft`（默认） | 现有MAT→2000点原始信号→模型追加25个零→单通道45×45 |
| `--input stft` | 项目已有单通道64×64 STFT图片→同一MFEML网络；末端特征池化至2×2以保持256维分类头 |

原始输入保留幅值，不插值、不新增归一化、不重新制作图片。复用项目采样起点，每个原项目窗口取前2000点；原始2000点和STFT整窗并非完全相同信息量。

## 默认参数

| 参数 | 默认值 | 依据 |
|---|---|---|
| 元更新次数 `--epochs` | **500（上限）** | 用户指定；论文表2为1000 |
| 任务批量 `--meta-batch-size` | 25 | 论文表2 |
| 内循环 `--train-steps` / `--test-steps` | 10 / 10 | 论文表2；验证也用test-steps |
| 内层/外层学习率 | 0.1 / 0.01 | 论文表2base/meta-learning rate |
| 主干 | 4块、64通道、3×3，FC输入256 | 论文表2与图2 |
| 优化 | 内层梯度下降、外层Adam；恒定学习率 | 式6–8及§3.4，无额外调度 |
| 提前停止 | 默认 `--patience 100` | 验证准确率连续100轮无严格提升则停止（持平计入），恢复最佳权重测试；`--patience 0`关闭 |
| SimAM λ / ECA核 | 1e-4 / 3 | 原文未给，固定实现补充 |
| 外层梯度裁剪 | 范数1；`--grad-clip 0`关闭 | 数值稳定补充 |
| 任务与测试 | 项目5-way、1/3/5-shot、15-query、seed3/24/38；1000测试episode | 保留项目协议 |

若仍需100轮实验，可明确加 `--epochs 100`。不修改其他对比模型的默认参数。不同预算、输入或方法配置不能混作同一对比单元。

## 文件与输出

- `mfeml_model.py`：自适应方阵、元特征增强、CNN、二阶MAML内循环。
- `raw_input.py`：现有MAT窗口读取与原始2000点接口。
- `run.py`：检查、训练、独立测试、结果与复现信息保存。
- `PyCharm本地运行命令清单.md`：完整可复制命令。

正式结果只写本目录的 `runs/<dataset>_<raw2000或stft64>_<shot>s_<时间>/<任务>_s<seed>/`，不会覆盖已有AMAML、TUBR-ML或主模型结果。保存 `best.pt`、resolved_config、method_config、architecture、code_sha256、source_snapshot、data_signature、history.csv、episodes.jsonl、test_predictions.csv、result.json；原始分支另存raw_window_manifest。完整三seed才输出mean±sample SD。

默认 `--action check`，不会意外启动500轮训练。训练需显式 `--action train`，不自动恢复中断训练或跳过已完成任务。独立测试从保存配置恢复输入方式，并核对源码、数据和权重哈希；CPU/CUDA不保证逐位相同，建议固定设备。

## 验证状态

2026-10-13已完成以下验证：

- 7项数值/行为检查通过：自适应补零及其梯度、SimAM能量公式和并行融合、两种输入形状、式6一步更新、任务参数隔离、二阶梯度有限差分及ECA梯度、query标签不参与适应、论文默认值与路径映射。
- seed24下13个任务/输入组合检查通过：PU两种输入各P1–P4，CWRU原始C0–C3与STFT C3。每类120源域训练/20目标验证/20目标测试；原始样本 `[1,2000]`、STFT `[1,64,64]`。
- PU P1 1-shot、CWRU C3 5-shot各两种输入，共4组CUDA单轮训练：**每组仍用完整25任务批次、训练/测试10步、inner0.1/outer0.01**，验证和测试缩减到各2个episode。保存后独立回读逐query预测完全一致；原始窗口2000点全部在所属分段内，禁止STFT生成检查通过。

以上仅验证数值与运行流程，不是1000轮正式实验，也不证明达到原文性能。验证脚本、日志、冒烟目录、PDF提取/截图和计划按用户要求清理；保留交付代码与说明，已有正式实验结果不变。
