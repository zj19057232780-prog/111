# 跨数据集实验使用说明

## 1. 与原项目的关系

新增config_cross_dataset.py、cross_dataset_data.py、run_cross_dataset.py和summarize_cross_dataset.py。复用现有模型、PAG-R、二阶MAML及任务采样基础实现，不修改原PU/CWRU/HUST配置或入口。新数据位于cross_data_processed，权重位于model_save/cross_dataset，结果位于results/cross_dataset。

本方案为目标验证辅助的跨数据集少样本迁移：目标验证标签用于选择checkpoint，目标测试query标签仅用于计分。没有运行正式长训练；tmp中的快速验证结果不能用于论文比较。

## 2. 配置切换

编辑config_cross_dataset.py中的CROSS_CONFIG：

```python
'task': 'T1',                 # T1至T6；也可在入口中使用all
'method': 'configured_maml',  # configured_maml / maml / protonet / tl_wdcnn
'k_shot': 1,                  # 1或5
'seed': 24,                   # 正式实验计划3、24、38
'run_mode': 'train_test',     # train / test / train_test
```

不传命令行动作时执行run_mode；CLI只覆盖显式填写的配置项。显式--test仅测试，--preprocess单独使用仅预处理。

| 域 | 所选数据 |
|---|---|
| A | CWRU C3，3hp，48kHz驱动端；Healthy、IR_007、OR_007（6点钟） |
| B | PU N15_M01_F10；K001、KI01、KA01；默认第1条记录 |
| C | 河内HUST v3，6205、0W；N500、I500、O500的稳态data |

T1=A→B，T2=B→A，T3=A→C，T4=C→A，T5=B→C，T6=C→B。全局类别0/1/2为N/I/O，训练验证测试均为3-way；原5-way权重不能直接使用。

## 3. 运行命令

在IFMAML-master目录的ifmaml2环境中运行。

首次预处理（三域共享一份数据，已在本次实现中生成并验收）：

```powershell
python run_cross_dataset.py --preprocess
```

重复预处理会核验数据签名、原始记录哈希和产物哈希后复用；配置变化或目录残缺时报错，不删除任何已有目录。修改预处理参数时使用新目录：

```powershell
python run_cross_dataset.py --preprocess --processed-root ./cross_data_processed_v2
```

按配置训练并测试：

```powershell
python run_cross_dataset.py
```

显式选择任务、方法和shot：

```powershell
python run_cross_dataset.py --task T1 --method configured_maml --shots 1 --seed 24 --train --test
python run_cross_dataset.py --task T2 --method maml --shots 5 --seed 24 --train --test
python run_cross_dataset.py --task T1 --method protonet --shots 1 --seed 24 --train --test
python run_cross_dataset.py --task T1 --method tl_wdcnn --shots 1 --seed 24 --train --test
```

顺序执行六任务（会开始正式训练，耗时取决于模型和早停）：

```powershell
python run_cross_dataset.py --task all --method configured_maml --shots 1 --seed 24 --train --test
```

仅测试已有同配置权重：

```powershell
python run_cross_dataset.py --task T1 --method configured_maml --shots 1 --seed 24 --test
```

启动时检查Actions行，只有train=True才会训练。配置、任务、shot或数据不匹配时拒绝测试；修改训练/模型参数后默认权重名称也会变化。若使用--model-path自定义路径，训练和测试必须使用同一路径前缀（不带_best）；已有checkpoint拒绝覆盖，不自动续训。结果每次写入独立时间戳目录。

快速功能验证：

```powershell
python run_cross_dataset.py --task T1 --method configured_maml --quick --train --test
```

快速模式只做1次元更新（TL-WDCNN为1个监督batch）、1个验证episode、2个测试episode；具有独立配置哈希和_quick权重名，结果标记quick_checkpoint=true。测试快速权重也要传--quick。参数量与正式模型一致，但准确率没有论文证据意义。

## 4. 数据与评测

每域每类40个非重叠窗口，共360个波形/图像对；作为源域时每类40训练，作为目标时每类20验证、20测试。原始信号先分成两个时间区间，中间留一窗口长度隔离带，再各区间独立抗混叠重采样，避免滤波跨集合。

PU为64→48kHz，HUST为51.2→48kHz，CWRU保留48kHz；统一3072点、STFT Hann 192/144、64×64灰度图。raw npy保留重采样波形，TL-WDCNN加载后逐窗归一化；图像由完全相同的波形生成。原始MAT及旧图片不变。

每episode每类15 query；1/5-shot使用相同查询样本，1-shot支持集嵌套于5-shot候选中。图像模型与TL-WDCNN共享episode清单；每次目标适配恢复模型/BN状态，验证不推进训练随机状态。1000个episode从有限窗口池重复抽取，不能当作1000批独立采集数据。

SCG-MAML、MAML、ProtoNet使用元训练与目标验证选模；TL-WDCNN从随机初始化进行源域监督训练，再逐目标episode复制模型、建立三类局部头并只使用support微调。当前入口支持上述四模型，不自动接入普通ResNet18或尚未复现的近期方法。

## 5. 结果与汇总

每次测试输出summary.json、config.json和predictions.csv，含准确率、macro-F1、三类混淆矩阵、逐episode准确率、数据/任务清单及权重来源。

完成正式实验后运行：

```powershell
python summarize_cross_dataset.py
```

生成comparison.csv及comparison_sources.json。默认只纳入1000episode、seed3/24/38的非快速结果。同一方法/shot/任务/seed重复测试取最新记录；任一单元格缺少种子就标incomplete，不用部分结果填满表格。Average先按seed平均六任务，再求跨seed均值与样本标准差；不同数据或任务清单禁止混表。

## 6. 验证

```powershell
python -m unittest test_cross_dataset -v
```

覆盖六任务样本隔离、所有360组原始数据重现、跨模型与shot清单一致、二阶梯度、查询标签隔离、评估状态恢复、错误配置拦截、四模型1/5-shot及全部迁移方向的小规模训练/权重回读，以及统计汇总公式。测试权重写入tmp独立目录，不覆盖正式权重。
